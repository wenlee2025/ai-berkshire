# 0002. 專注美股與台股研究並廢除中港股模組

## 狀態
Accepted (已採納)

## 背景與問題
原專案涵蓋美股、港股、A 股多市場，導致信源分散（需維護巨潮、東財、港交所披露易、aastocks、雪球等），爬蟲維護成本高且資訊品質不均。
為提升投資研究深度與數據嚴謹度，決定將標的明確收斂至「美股（US Equities）」與「台股（Taiwan Equities）」。

## 決策
1. **完全移除中港股工具與依賴**：
   - 刪除 `tools/ashare_data.py` 與 `tools/xueqiu_scraper.py`。
   - 清理所有技能與選股清單中的中港股信源與標的（如騰訊 0700、茅台 600519 等）。
2. **重構美股與台股對稱工具鏈**：
   - **美股**：以 SEC EDGAR、Macrotrends、StockAnalysis 為主要信源，並開發標準庫零外部依賴的 `tools/usstock_data.py`。
   - **台股**：以 FinMind API (`tools/twstock_data.py`)、Goodinfo 與公開資訊觀測站（MOPS）為核心，充分發揮台股「強制月營收披露」與「高股息殖利率」之分析優勢。
   - **選股篩選器**：升級 `tools/stock_screener.py`，預設池配置美股重點賽道與台股半導體/伺服器/權值股分組，並支援台股月營收動能篩選。
3. **20 個 Skills 全面改寫**：
   - 全面更新 `skills/*.md` 中的資料源清單、提示詞步驟、範例與檢查清單。
   - 保留 `reports/` 下歷史報告作為存檔紀錄，不予篡改。

## 後續影響
- 研究流程與工具鏈更精簡、高可用且零外部第三方包依賴。
- 聚焦兩大核心市場，分析質量與數據交叉驗證效率大幅提升。
